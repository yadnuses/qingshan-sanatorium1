# 《口业》游戏设计文档

## 概述

**定位**：《青山疗养院》与《逐日塔迷雾》之间的衔接作品
**形式**：纯文字视觉小说，HTML/CSS/JS实现
**时长**：30-45分钟，8个选择点
**风格**：黄色旧羊皮纸 + 冷酷风格，无音效无立绘
**主题**：语言暴力、友谊背叛、谣言的自我增殖

---

## 核心概念

"口业"取自佛教用语，指由言语所造的恶业。游戏以第一人称视角讲述一个大学女生被亲密好友通过谣言摧毁社会关系的故事，同时穿插超自然元素，为续作《逐日塔迷雾》铺设伏笔。

**核心矛盾**：在失去哥哥（周明远）后，唯一的精神支柱——好友L——也在用谣言瓦解她的生活。

**超自然策略**：模糊现实与超自然的边界。玩家永远无法确定是人心的恶意还是超自然力量的介入。

---

## 叙事结构

### 双时间线 + 碎片化旁证

**主轴**：晚晴第一人称的"现在"时间线（线性推进）

**穿插元素**：
- **回忆片段**：与L的美好过去，由特定事件触发，带有暖色滤镜
- **L的独白碎片**：逐步揭示L的心理，用斜体暗红色呈现
- **论坛/监控碎片**：客观旁证，模拟论坛截图和监控终端
- **周明远笔记**：串联青山疗养院和逐日塔迷雾的线索

### 章节设计

#### 第一章：未读邮件

**现在**：整理周明远遗物，发现加密邮件。回到青山大学。

**回忆**：与周明远最后一次通话（交代人物关系——表兄妹）。

**碎片**：新闻报道片段（疗养院大火的客观描述）。

**选择点**：
1. 是否打开邮件 → 影响后续对周明远调查的了解程度
2. 是否告诉L → 影响L后续的行为模式

**超自然**：窗外有光从后山方向掠过（轻微，玩家可能忽略）。

#### 第二章：旧友

**现在**：开学，L作为同班好闺蜜主动照顾晚晴，两人恢复日常。

**回忆**：L帮晚晴占座、一起吃饭的温馨画面（但暗藏伏笔——L习惯用"为别人做事"来维系关系）。

**碎片**：L的内心独白第一次出现（很短，玩家不知道说话者是谁）。

**选择点**：
3. 是否对L敞开心扉 → 影响后续谣言爆发时的冲击力度

**超自然**：无。

#### 第三章：种子

**现在**：第一个谣言爆发——"晚晴追C的时候C和前女友还没断干净"。在水房听到隔壁议论。

**回忆**：晚晴追C时L全程帮忙画时间线、分析聊天记录的画面（对比现在的背叛）。

**碎片**：论坛匿名帖截图、同学窃窃私语。

**选择点**：
4. 是否当面质问L → 选择质问会解锁更多L的独白碎片
5. 是否向C求证 → 选择求证会解锁C的视角碎片

**超自然**：无。

#### 第四章：回声

**现在**：第二个谣言——伪造的录音，晚晴"辱骂F教授"。录音确实是晚晴的声音，但她从未说过那些话。

**回忆**：与F教授的真实对话（证明晚晴从未说过那些话，F教授笑着说"有批判精神是好事"）。

**碎片**：监控画面（暗示录音来源）、L的独白第二次出现（更长，透露她的焦虑和恐惧）。

**选择点**：
6. 是否公开澄清 → 影响超自然渗透度（选择澄清，超自然元素更明显）

**超自然**：开始听到耳鸣般的低频嗡声（在谣言传播时）。

#### 第五章：暗面

**现在**：第三个谣言——照片被裁剪，晚晴和S学长被说成"深夜私会"。

**回忆**：与S学长打《黑暗之魂》的完整画面（网吧通宵刷成就，周围还有其他人）。

**碎片**：照片原始版本（暗示拍摄者是L，她当时说在自拍）、周明远笔记第一次出现（提到"青山大学也有异常"）。

**选择点**：
7. 是否彻底断绝与L的关系 → 影响最终对峙的情感基调

**超自然**：逐日塔灯光第一次在游戏中出现，青白色冷光。

#### 第六章：口业

**现在**：与L的最终对峙。L拿着两杯奶茶，笑容和往常一样。晚晴质问三个谣言。

**回忆**：一个从未出现过的回忆——大学入学时L说的第一句话（揭示L的性格底色）。

**碎片**：L的独白完整版（揭示她的心理：恐惧被孤立、嫉妒晚晴拥有她没有的东西、用别人的秘密换取社交安全感）。

**超自然**：
- 日记本上出现陌生字迹："你哥哥发现了疗养院的秘密，所以他消失了。现在轮到你了。"
- 逐日塔灯光变亮
- L的笑容微妙变形

**选择点**：
8. 对峙方式：质问 / 沉默 / 尝试理解 → 影响情感路径和碎片解锁

**结局**：无论选择什么，晚晴最终走向后山。走廊声控灯不亮，尽头有脚步声在模仿她的步频。

#### 尾声：后山

线性推进。逐日塔在午夜十二点亮起青白色灯光。晚晴朝着后山走去。

文字渐隐：**"【口业·终】"**
衔接文字：**"【下一章：逐日塔迷雾——加载中】"**

## 角色设计

### 晚晴（"我"）
- 周明远的表妹，青山大学文学院学生
- 性格：内敛、敏感、重感情，习惯信任身边的人
- 核心矛盾：在失去哥哥后，唯一的精神支柱L也在瓦解
- 名字"晚晴"暗示"雨过天晴"——但《口业》中她经历的是暴风雨

### L（核心反派/悲剧角色）
- 晚晴的大学同班同学、好闺蜜
- 性格：表面热情开朗，内心极度恐惧被孤立
- 核心动机：她不是天生恶意，而是"用别人的秘密换取社交安全感"
- 她的独白碎片逐步揭示：她知道自己在做什么，但停不下来

### M（周明远）
- 晚晴的表哥，调查记者
- 在《口业》中已"死亡"（疗养院大火），只通过回忆和遗物出现
- 他的调查笔记是串联青山疗养院和逐日塔迷雾的关键线索

### C、S学长、F教授
- 功能性角色，推动谣言剧情
- 不需要深入刻画，但需要让玩家感受到谣言对他们的影响

### 超自然存在（模糊）
- 日记本上的陌生字迹、逐日塔的灯光
- 永远不明确是幻觉还是真实
- 为逐日塔迷雾做铺垫

---

## 选择机制

玩家在8个关键节点做出选择。选择不改变最终结局（走向后山），但影响三个维度：

### 1. 情感路径
- **隐忍**：晚晴默默承受，内心积压
- **对抗**：晚晴正面反击，但可能激化矛盾
- **逃避**：晚晴试图回避，但谣言追着她

### 2. 碎片解锁
不同选择解锁不同的旁证碎片：
- 选择"向C求证" → 解锁C的视角碎片
- 选择"质问L" → 解锁更多L的独白
- 选择"沉默" → 解锁论坛匿名帖的完整版本

### 3. 超自然渗透度
- 选择越"对抗"，超自然元素越明显（塔楼灯光更频繁、嗡声更响）
- 选择越"隐忍"，超自然元素越隐蔽，更像心理压力

### 碎片旁证展示机制

**回忆片段**：在关键剧情节点自动触发，画面切换为回忆场景，结束后回到现在。

**L的独白**：在每章末尾自动出现，以斜体暗红色文字呈现，不标注说话者身份。玩家到第六章才知道这些独白来自L。

**论坛/监控碎片**：在场景中以"可点击元素"出现（如下划线文字、高亮区域），玩家点击查看。不点击也不影响主线推进。

**周明远笔记**：在特定章节末尾自动展示，不可跳过，是衔接剧情的关键信息。

## 视觉设计

### 主视觉
- 背景：泛黄旧羊皮纸质感，带有褶皱和污渍
- 文字：冷灰色主色调，关键信息用暗红色
- 整体风格：像一份被时间侵蚀的档案/日记

### 文字呈现
- 主叙事：宋体/楷体，正文大小
- L的独白：斜体，颜色偏暗红，像被划掉又重新写上的字
- 论坛碎片：模拟论坛排版，用户名用乱码
- 监控碎片：等宽字体，绿色/白色，模拟终端
- 周明远笔记：手写风格字体，潦草但有力

### 超自然视觉
- 逐日塔灯光：在羊皮纸背景上出现青白色光晕
- 日记本字迹：文字逐渐扭曲变形
- 谣言爆发时：文字抖动、重影

## 与前作和续作的衔接

### 从《青山疗养院》继承的元素
- 周明远：青山疗养院的主角，在《口业》中已"死亡"
- 疗养院大火：开场背景
- 加密邮件："青山市的故事远远没有结束"
- "有些话一旦说出口，就会自己长脚跑"

### 为《逐日塔迷雾》铺设的伏笔
- 逐日塔：多次出现灯光异象，但始终不解释
- 后山：游戏结尾走向后山
- 火球：与疗养院大火的火球呼应
- "青山大学也有异常"：周明远笔记中的暗示
- 日记本字迹：从模仿到"不像人写的"

### 隐藏彩蛋
- 搜索"青山疗养院"可跳转到青山疗养院页面
- 在《逐日塔迷雾》中可找到《口业》中晚晴留下的痕迹

## 技术实现

### 技术栈
HTML/CSS/JS，与《青山疗养院》一致。

### 核心系统
1. **剧本引擎**：JSON定义剧本结构，JS渲染对话和选择
2. **选择系统**：记录玩家选择，影响后续内容展示
3. **碎片系统**：根据选择解锁不同旁证碎片
4. **超自然系统**：根据选择调整超自然元素的呈现强度

### 部署
与《青山疗养院》同一项目，独立目录结构。
